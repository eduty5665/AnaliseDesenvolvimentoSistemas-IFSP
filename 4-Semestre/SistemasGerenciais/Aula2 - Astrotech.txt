PIRAMIDE HIERARQUICA
	
	NIVEL ESTRATEGICO
	NIVEL GERENCIAL/TATICO
	NIVEL OPERACIONAL/TRANSACIONAL

**SAZONALIDADE: Periodico, algo que acontece mais em um periodo doq em outro, é algo sazonal.**

--OPERACIONAL
	Vendido, entrou no estoque, faturamento (preço praticado)
	Informações basicas,, informações diarias, rotineiras
	Internas e Detalhadas

--GERENCIAL
	Composição de duas ou mais informações operacionais
	união das informações internas
	aglomerado de informações para mandar pro estrategico
	Internas e mais sucintas

--ESTRATEGICO
	Gotejamento, união das informações
	internas e externas
	mais superficiais, traz os dados mais importantes
	une todas as informações 
	para tomada de decisão

Em cada Nivel organizacional tem um tipo diferente de informação, sendo necessario um sistema de informação especifico para cada nivel organizacional

Empresa Ficticia ASTROTECH
	cada grupo representa um setor dessa empresa
	que usa e/ou fornece informações para outros setores ou para o proprio setor
	interno/externo

	dificuldade maior --> não compartilhamneto das informações
	solução --> criar um sistema de informação

	 A PENSAR:
	pensar nas informações que envia e/ ou recebe
	dados internos e externos
	evitar erros
	sistema de informação = estrategia
	infos que o sistema toma com base nos dados
	tomada de decisão

RASCUNHO

--Informações Recebidas

	Produto & Estoque
	quantidade atualizada
	dados tecnicos
	funcionamento

--Funcionamento do Setor

	Buscar publico alvo
	Nicho de mercado para cada produto
	especificidade
	saber qual cliente/empresa é melhor para cada produto
	propaganda/divulgação nichada
	campanhas mais acertivas
	visando determinado publico alvo

--Informações Enviadas

	Publico Alvo
	Qual publico mais consome
	redes sociais - insights
	visar - criação de produtos novos
	focando na real necessidade do cliente
